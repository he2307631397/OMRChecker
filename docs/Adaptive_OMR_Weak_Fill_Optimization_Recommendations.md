# Adaptive OMR 弱填涂识别优化建议总结

## 1. 当前设计评价

当前弱填涂优化方案整体方向正确：

-   保持正常识别链路不变。
-   仅对正常识别失败的空白字段进行 fallback。
-   不通过降低全局阈值解决弱填问题。
-   不使用增强图替代主识别输入。
-   所有 fallback 结果需要记录诊断信息。

该方案适合作为商业级 OMR 系统的第一阶段优化方案。

核心原则：

> 主识别结果优先，弱填涂恢复作为受控补偿机制。

------------------------------------------------------------------------

# 2. 建议增加：墨迹置信度模型（后续版本）

当前方案主要依赖：

-   mean 灰度
-   gap
-   delta

但弱填涂本质不是寻找最黑区域，而是判断：

> 当前区域是否存在人为填涂行为。

建议未来增加 Mark Score。

## MarkScore

可以由多个特征组成：

    MarkScore =
        DarknessScore
      + DensityScore
      + ShapeScore
      + DistributionScore

------------------------------------------------------------------------

## 2.1 DarknessScore

已有设计：

    blank_mean - candidate_mean

表示候选区域比空白区域暗多少。

------------------------------------------------------------------------

## 2.2 DensityScore（推荐优先增加）

淡涂通常不是整体变黑，而是部分区域存在笔迹。

增加：

    dark_pixel_ratio

例如：

统计：

    pixel < threshold

的比例。

效果：

强填：

    dark_pixel_ratio 高

弱填：

    dark_pixel_ratio 中等

空白：

    dark_pixel_ratio 低

相比单纯 mean，更能识别淡涂。

------------------------------------------------------------------------

## 2.3 ShapeScore

区分：

-   人工填涂
-   灰尘
-   扫描噪声
-   边框线

可使用：

-   连通区域面积
-   填充面积比例
-   ROI 覆盖率

------------------------------------------------------------------------

## 2.4 DistributionScore

判断是否为孤立异常点。

例如：

候选 A：

    mean=210
    density=30%

其他候选：

    mean=245
    density=5%

可信度高。

------------------------------------------------------------------------

# 3. 优化空白模型

当前：

    lighter half candidates

作为 blank baseline。

可以进一步升级为：

## Page Blank Distribution

建立页面级空白模型：

保存：

    BlankDistribution
    {
        mean,
        std,
        density
    }

然后使用：

    z-score =
    (blank_mean - candidate_mean) / blank_std

判断候选是否明显偏离空白分布。

优势：

-   适应不同扫描仪。
-   适应不同纸张。
-   降低固定参数依赖。

------------------------------------------------------------------------

# 4. 增加二次图像分析

增强图像不建议作为主流程。

但 fallback 阶段可以增加辅助分析。

优先推荐：

## 多阈值二值分析

不要直接 CLAHE。

例如：

多个阈值：

    180
    200
    220
    240

统计：

    occupied pixels

比较不同候选。

人工填涂区域通常随着阈值变化保持增长趋势。

优势：

-   简单。
-   稳定。
-   对扫描环境适应性更好。

------------------------------------------------------------------------

# 5. 增加字段类型策略

不同字段错误成本不同。

建议增加：

    RecognitionPolicy

例如：

## 单选题

允许：

-   单候选恢复。
-   中等置信度 fallback。

------------------------------------------------------------------------

## 准考证号 / 身份字段

要求更高：

-   更高 confidence。
-   邻位检查。
-   页面级弱填判断。

原因：

答案错误影响一道题。

身份错误影响整张卷。

------------------------------------------------------------------------

## 多选题

保持独立逻辑：

-   不复用单选评分。
-   支持合法多标。
-   支持 ABCD 全选。

------------------------------------------------------------------------

# 6. 增加准考证号序列检查

Identifier 不应该只看单格。

建议增加：

## Identifier Sequence Model

检查：

-   相邻位置是否同时异常。
-   是否多个 fallback。
-   是否符合长度。
-   是否存在冲突候选。

例如：

    820159

识别：

    8 ? 0 ? 5 9

需要结合上下文判断。

------------------------------------------------------------------------

# 7. 增加人工审核闭环

商业系统需要输出：

    adaptive_review.csv

包含：

  字段              说明
  ----------------- ----------
  sheet             试卷编号
  field             区域
  normal_result     原结果
  adaptive_result   恢复结果
  confidence        置信度
  diagnostics       诊断信息

人工确认结果可以作为后续模型训练数据。

------------------------------------------------------------------------

# 9. 实施优先级

保持当前设计：

-   主识别不变。
-   fallback only。
-   日志审计。

增加：

1.  density score。
2.  页面 blank distribution。
3.  z-score。

------------------------------------------------------------------------

## P1 第二阶段

增加：

1.  多阈值二值分析。

------------------------------------------------------------------------

## P2 第三阶段

# 10. 针对当前弱填10张测试的建议

当前数据：

    q5:
    mean=209
    gap=25
    delta=45

    q3:
    mean=205
    gap=10
    delta=39

    q6:
    mean=158
    gap=49
    delta=75

分析：

-   q6 基本可以直接恢复。
-   q5 具备较高恢复条件。
-   q3 单纯依赖 gap 可能不足。

因此：

仅使用：

    local_delta + gap

可能遗漏部分弱填。

增加：

    density score
    +
    blank distribution

可以提高稳定性。

------------------------------------------------------------------------

# 结论

当前 Adaptive Weak-fill Recognition Design 不需要推翻。

推荐演进方向：

    自适应弱填涂识别
    =
    正常识别保护
    +
    页面空白模型
    +
    多特征候选分析
    +
    字段风险策略
    +
    审计闭环

第一阶段先完成规则增强，后续再引入机器学习评分模型。
