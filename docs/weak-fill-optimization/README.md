# OMRChecker 淡涂优化输出文档

本目录集中保存淡涂优化过程中的可追溯文档，避免项目根目录和 `docs/` 根目录继续膨胀。

## 目录用途

- `status.md`：当前优化阶段、提交记录、验证结果和下一步。
- `regression-summaries/`：人工整理后的四场景回归摘要。
- `feature-analysis/`：淡涂、正常、没涂满、涂超出特征分布分析。
- `decisions/`：关键方案取舍，例如是否启用自动恢复。

## 不放入本目录的内容

以下内容属于运行产物，默认不提交：

- `outputs_jcode_*`
- `jcode_*.log`
- `.jcode_runs/*`
- 原始扫描资产和压缩包

运行产物只用于当轮验证。需要长期保留时，应先整理成摘要 Markdown 后放入本目录。
